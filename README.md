# Mohan Prasad N — Software Engineer Portfolio

> Built to mirror the editorial layout and interactions of [Majd's Framer Portfolio](https://majd-portfolio.framer.website/).  
> Clean HTML5, CSS3, and vanilla JavaScript with zero third-party framework overhead.

---

## 🌟 Key Interaction Features

1. **Top Single Dropdown Box**:
   - Sleek dark pill with pulsing status indicator.
   - Expandable dropdown menu with numbered sections.

2. **Scroll-Driven Image Zoom**:
   - Centered profile photo positioned at the bottom of the home stage against giant `SOFTWARE ENGINEER` watermark lettering.
   - Smoothly zooms and transitions toward the center as the user scrolls.

3. **Two-Sided About Section**:
   - Left column: Greeting and background at Government College of Engineering, Salem.
   - Center column: Centered portrait photo.
   - Right column: Certifications, SIH 2025 finalist experience, and technical focus.

4. **Typewriter Effect for Skills**:
   - Skill headings type out character-by-character as they enter view.

5. **2×2 Project Grid**:
   - Vector SVG mockups with hairline borders and direct repository links.

6. **Experience Timeline & Contact**:
   - Milestone tracker and minimalist contact section with 1-click clipboard copy buttons.
