## ◈ Overview

Welcome to my personal developer portfolio.

This website represents my journey as a Computer Science Engineering student at **Government College of Engineering, Salem**, with a strong interest in Java development, backend engineering, and full-stack technologies.

Rather than following a conventional portfolio layout, this project introduces an interactive developer workspace with smooth transitions, scroll-based animations, minimalist typography, and an organized presentation of my work.

**The goal is simple:** Present my technical journey through an experience that feels like exploring a developer's digital workspace.

## ◈ Experience & Interactions

The portfolio focuses on an interactive browsing experience with the following features.

| Feature | Description |
|:---|:---|
| Navigation System | Minimal dark pill-shaped dropdown with a pulsing status indicator and numbered navigation sections. |
| Scroll-Driven Animation | Profile image smoothly zooms and transitions toward the center while scrolling. |
| Hero Section | Centered profile image positioned against oversized SOFTWARE ENGINEER typography. |
| About Section | Two-sided layout presenting my background, certifications, achievements, and technical interests. |
| Typewriter Animation | Skill headings reveal themselves character by character as they enter the viewport. |
| Project Showcase | Structured 2×2 project grid with custom SVG-based visual mockups and repository links. |
| Experience Timeline | Minimal milestone-based timeline highlighting academic and professional development. |
| Contact Interaction | One-click clipboard copy functionality for convenient communication. |

## ◈ Design Philosophy

The portfolio follows a minimal, dark, developer-oriented visual language.

- **Minimalism:** Avoid unnecessary visual elements.
- **Interaction:** Use animations to improve the browsing experience.
- **Typography:** Strong typography creates visual hierarchy.
- **Consistency:** Maintain a unified design throughout every section.
- **Usability:** Keep navigation, project access, and contact information straightforward.

## ◈ Run Locally

Want to explore the source code or run the portfolio locally?

### 1. Clone the repository

```bash
git clone https://github.com/M0han05/Portfolio.git
```

### 2. Navigate to the project directory

```bash
cd Portfolio
```

### 3. Start the local development server

```bash
python3 -m http.server 3000
```

### 4. Open in your browser

```text
http://localhost:3000
```
