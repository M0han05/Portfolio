## `01` — Overview

This repository contains my personal developer portfolio, designed as an interactive workspace rather than a conventional portfolio website.

Inspired by code editors and developer environments, the interface presents my background, projects, technical skills, education, and credentials through a file-explorer-inspired layout.

The goal is simple: make exploring a developer's work feel like exploring their workspace.

## `02` — Interface

| Workspace File    | Contents                                        |
| :---------------- | :---------------------------------------------- |
| `overview.md`     | Introduction, biography, and professional goals |
| `projects.json`   | Selected projects and their descriptions        |
| `skills.yaml`     | Technical skills and current learning areas     |
| `credentials.txt` | Education and certifications                    |
| `contact.sh`      | Interactive contact interface                   |
